# Reported

Native Android and iOS apps for reporting unsafe driving and parking, with shared Kotlin Multiplatform business logic.

## Projects

- [Android](native/androidApp): Jetpack Compose app.
- [iOS](native/iosApp): SwiftUI app, with an Xcode project generated by XcodeGen.
- [Shared core](native/shared): networking, authentication, session storage, reports, and use cases.
- [Slack-to-Discord bridge](slack-to-discord): active service for mirroring Slack messages to Discord. See its [setup guide](slack-to-discord/README.md).
- [Complaint animations](tools/complaint-animations): SVG and Lottie generation tools.

## Run the apps

See the [native setup guide](native/README.md) for prerequisites and required configuration. Commands below start at the repository root.

Android:

```sh
cd native
./gradlew :androidApp:assembleDebug
./gradlew :androidApp:installDebug
```

The install command requires a running emulator or connected Android device.

iOS (macOS):

```sh
cd native/iosApp
xcodegen generate
open ReportediOS.xcodeproj
```

Select the `ReportediOS` scheme and an iOS simulator in Xcode, then Run.

## Development

The apps use state, actions, and effects as described in [UDF.md](native/UDF.md).
Shared assets in `assets/` are also consumed by Android; keep them when modifying native resources.

The old Expo/React Native application source has been removed. Each project above has its own tooling; there is no root npm app to install or start.
