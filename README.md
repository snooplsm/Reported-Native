# Reported React Native
## Installation
- Install [NodeJS](https://facebook.github.io/react-native/docs/getting-started)
- Install the [Expo iOS Client](https://apps.apple.com/us/app/expo-client/id982107779) app on the App store


## Running locally
- Run `npm i` to install packages
- Run `npm start` to start the local build
- [App testing] Scan the QR code with your phone and open the Expo client app to run the app locally.
